# Código recebido do Florest Bar Windows

Importado do arquivo `Nova pasta.zip` enviado pelo proprietário em 08/11/2026, na pasta `florest-bar-windows` do repositório Florest-Sistemas. O código do aplicativo foi preservado como recebido.

O ZIP inclui fontes, scripts, testes, interface preparada, package.json, package-lock.json e configuração NSIS. Não inclui a pasta resources, node_modules, dist ou o instalador compilado.

Para gerar o instalador, é necessário fornecer os recursos referenciados pelo projeto, incluindo resources/print-agent.exe e resources/print-agent.json. O README original também descreve resources/modelos-1.0.0.json, ausente neste envio.

Na importação foi validada a sintaxe com `node scripts/check.cjs`. As informações históricas de testes no README original foram fornecidas com o projeto; não representam testes repetidos nesta importação. Não houve homologação Windows, impressão física ou compilação do instalador nesta importação.
