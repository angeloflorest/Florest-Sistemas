# Referência do backend instalado

Snapshot somente de estrutura e código, recuperado em leitura em 23/10/2026 do projeto etulhyboogqhyyevpnlo. A pasta 2026-10-23 registra 148 funções relacionadas a usuários, vendas, caixas, Bar, financeiro e dependências, além de metadados das estruturas envolvidas. O manifesto das Edges identifica as cinco versões recuperadas.

Não contém registros dos clientes nem substitui backup de dados. JSONs não são migrações. ACLs e proprietários foram registrados para comparação; a reconstrução em outro ambiente exige organizar dependências e revisar privilégios. Não executar automaticamente esses fontes sobre produção.

A definição anterior do cancelamento acompanha a proposta em ../atualizacoes-pendentes. O comportamento vigente no Supabase só muda quando uma atualização for explicitamente aplicada lá.
